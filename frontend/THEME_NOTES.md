# Qaddir presentation-theme frontend

This version keeps the existing API/inference behavior and changes the visual layer only.

## Visual direction
- White / navy / electric-purple palette matching the Qaddir presentation
- Institutional Tuwaiq/Qaddir header lockup
- Soft lavender geometry, structured cards, restrained shadows
- Presentation-style workflow and verification language
- Existing upload, API health, CV result, verification, report, and error states preserved

## Run
```bash
npm install
npm run dev
```

The backend URL/configuration is unchanged.
